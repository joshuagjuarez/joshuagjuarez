# PothOS community and support

PothOS software is free, always. The public design source is available now;
the standalone runtime and hosted free-access migration remain in preparation.
If an older screen requests a PothOS software payment, contact support instead
of starting a new paid subscription.

## Available routes

| Need | Route | Visibility and current behavior |
| --- | --- | --- |
| Documentation, reproducible bugs or design proposals | [Public GitHub issues](https://github.com/joshuagjuarez/joshuagjuarez/issues/new/choose) | Public. Use reduced descriptions and synthetic examples. |
| Documentation contribution | A pull request in this repository; read [contributing](contributing.md) | Public source review. No private-system access is granted. |
| Account, historical billing or private support | [JoshOps support](https://joshops.ai/support) or [joshua@joshops.ai](mailto:joshua@joshops.ai) | The website provides an email contact. It is not a verified automatic ticket or private-stack relay. |
| Security concern | [Private security reporting](security.md) | Keep credentials, private records and sensitive exploit details out of public issues. |
| Partnership or press | [joshua@joshops.ai](mailto:joshua@joshops.ai) | Direct contact; no promised response deadline. |

You do not need a GitHub account to send email.

## What to include

Describe what you were trying to do, expected and observed behavior, the visible
error, and roughly when it occurred. Include the public documentation revision
or software version, operating system and relevant model/runtime version when
known. A short reproduction using synthetic data is more useful than an entire
environment export.

Remove passwords, access tokens, recovery codes, private URLs, banking details,
personal memories, embeddings, microphone recordings and other people's
records. A redacted screenshot may help, but review all visible text first.
Do not attach private configuration or raw logs just because a report form
allows attachments.

## Help Desk integration

The intended product includes useful local help and a voluntary path for
escalating a reduced report to maintainers. An automatic community Help Desk
connection into the founder's private stack has **not been verified**.
Opening a public issue or sending email does not grant access to that stack.

Any future relay must let the reporter preview and approve the payload and
destination, enforce authenticated account/tenant boundaries, preserve an
original request ID, return a receipt and support recovery without duplicate
effects. Private reports need separate redaction review and consent before
public promotion. These requirements are detailed in
[cognitive privacy](cognitive-privacy.md).

A sent report, an acknowledgment, triage and resolution are different states.
The project does not promise an immediate reply or a guaranteed fix.
