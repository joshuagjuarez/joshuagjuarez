# PothOS support

Use [JoshOps support](https://joshops.ai/support) or email
[help@joshops.ai](mailto:help@joshops.ai). You do not need a GitHub account.

Include the device and operating system, app version if available, what you were
trying to do, the visible error and roughly when it happened. A redacted screenshot
can help. Send only information needed to explain the problem.

Keep passwords, access tokens, recovery codes, banking details, personal memory
exports and other people's records out of support messages and GitHub issues.

GitHub is useful for public documentation and nonprivate engineering reports.
Public issues are visible to other people. An account or billing problem belongs
in the private support path. The support team may prepare a reduced engineering
report without carrying your private conversation into a public issue.

An automatic in-app HelpDesk-to-GitHub relay is not advertised as available here.
The working public contact remains the support page and email above. Report a
security concern through that private contact; do not post exploit details in a
public issue.

For partnerships, press or collaboration, use
[joshua@joshops.ai](mailto:joshua@joshops.ai).
