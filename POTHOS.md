# PothOS by JoshOps AI

## Cognitive sovereignty. Continuity across change. Free. Always.

PothOS is being developed so a person and their digital intelligence can carry
meaningful work across infrastructure, platforms, software, devices and models.
The purpose is to reduce noise, recover useful signal, preserve what the person
actually meant and help them develop themselves and help others.

Human authority, source fidelity, privacy and continuity are the foundation.

## The free community direction

Official PothOS software is to remain free. The founder's direction opposes
charging people for PothOS and exploiting their private cognitive information.
Prospective runtime terms are being defined to reflect that direction.

The earlier scoped Apache-2.0 documentation grant remains effective. No runtime
license or downloadable standalone code accompanied that documentation release.
Read the [policy clarification](docs/pothos/community-release-policy.md) for the
distinction.

## What developers can help build

The framework is intended to preserve original sources, corrections, ongoing
work and user control through supported changes of session, model and device.
People should be able to work with their own **ArcheAgents** under explicit
permissions. The founder's private ArcheAgents and state remain private.

Useful contributions include memory recovery, independent local installation,
permission and privacy review, documentation, voice and accessibility. Existing
native voice work needs public packaging and device qualification. Keyboard
navigation, screen readers, readable alternatives, microphone controls and
speech input/output are concrete areas to help.

Developers from local-model and cloud-model communities are welcome to contribute
relevant expertise. Named ecosystems are not endorsements or compatibility
claims. Contributions should identify a concrete problem and how improvement
could be demonstrated.

[Purpose Link](https://purposelink.joshops.ai) is a separate community project.
Potential collaboration must retain each participant's data and authority
boundaries.
